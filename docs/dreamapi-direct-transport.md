# DreamAPI 服务器直连（2026-09-18）

## 调用方式

API 生图默认使用 `DREAMAPI_CONNECTION_MODE=direct`：浏览器创建面板任务，服务器使用私有环境变量中的 `DREAMAPI_KEY` 请求 `DREAMAPI_BASE_URL/v1/images/generations`，随后保存图片并由浏览器查询面板任务结果。服务器不再通过 Windows 控制程序或 SSH 反向隧道提交 API 生图。

`DREAMAPI_BASE_URL` 支持 HTTPS 域名根路径或末尾 `/v1`，不会重复拼接版本路径。保持原 DreamAPI 账号、Key、模型选择、尺寸和质量参数。`size`、`quality` 是传给供应商的请求值；供应商若返回不同尺寸或质量，仍记录实际值，不能保证供应商严格遵循请求。最终画布按用户选择保存。

同机部署 Sub2API 时，也支持显式配置 `DREAMAPI_BASE_URL=http://127.0.0.1:8080/v1`（或 IPv6 数字回环地址）。该线路直接连接服务器本机服务，不经过公网域名或 Nginx；不依赖 Windows 或 ComfyUI。只有数字回环地址允许 HTTP，其他地址仍要求 HTTPS。同机 HTTP 请求忽略环境代理、拒绝重定向，保留现有 Bearer 鉴权、600 秒总等待上限、不自动重试及账本不确定性保护。容器内服务名 `sub2api` 不适用于运行在宿主机上的面板。

上述能力需发布代码后才能切换环境配置；文档中的地址不是线上已切换的声明。切换前确认端口映射、原 Key 的只读模型查询及无在途任务，切换后核对实际进程环境与健康状态。

本地 ComfyUI 的隧道与守护程序仍保留。需要退回旧 API 转发线路时，维护者可显式设置 `DREAMAPI_CONNECTION_MODE=workstation`，并配置原 `DREAMAPI_EGRESS_URL`。仅留下旧 EGRESS 环境变量不会改变新默认线路。

## 错误与恢复

- 接口返回的 `error` 无论是字符串还是包含 `message` 的对象，都保留服务端脱敏原因，再映射为固定中文提示。
- API、云端不设网站小时或每日生图次数上限。并发、重复请求 ID、会话归属保护继续有效。
- 直连提交前，将等待窗口写入任务账本。明确的非 408 HTTP 4xx 拒绝或收到完整 JSON 后解除窗口；断连、超时和不明确的 5xx 保留到原提交后的 660 秒，避免快速重提。该保护只占用 API 槽，不占用云端槽。
- 660 秒是有限等待窗口，不证明供应商已停止执行。同步 API 缺少可靠的结果查询标识，窗口结束后仍应核对供应商记录。不会自动重发付费 POST；超时线程也不等于供应商已取消。
- 同时接受 `data[].b64_json` 和 `data[].url`。URL 只允许公网 HTTPS；逐次检查重定向、固定已检查 IP、保留 TLS 主机名校验，不向图片域名发送 API Key。
- 图片 URL 在下载前写入私有账本字段 `api_result_url`，下载失败时保留，成功后删除；公开任务接口不包含该字段。维护恢复仅重新下载图片，不重新调用生图 API。
- 图片下载限制为 60 秒、32 MiB，沿用原图像格式、像素数与本地保存校验。

## 核验边界

健康检查的 `dreamapi_connection_mode` 表示实际配置模式，`dreamapi_transport_ready` 表示配置和等待窗口是否允许提交，不代表已经探测上游实时生图能力。

只读 `/v1/models` 探测已在正式服务器使用原 Key 返回 200。中间候选 `253be51` 的服务器直连 Flare low 9:16 单次生图成功，任务 `bd407ecb0ecc`，23.7 秒；后续最终版本出图证据单独保存，不能用中间版本代替最终版本验证。

参考项目为 `ai-image-web-backup` 提交 `edc93b5063a14d22b95890d84137807722cb97c7` 的普通绘图路径。没有迁移其媒体代理、独立供应商密钥、计费数据库或自动重发收费请求的行为。
