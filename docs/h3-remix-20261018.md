## Controls and execution

- Reference-to-video and image/first-last-frame modes, manual or source-aligned duration, resolution, aspect ratio, frame rate and custom dimensions.
- Independent second sampling and face refinement branches. Disabled branches and unused outputs are removed by dependency traversal before submission. With second sampling off, face refinement consumes the first output directly.
- Original/generated audio selection. The unused audio branch is disconnected, so an inactive switch input cannot force decoding.
- Three original LoRA rows with independent enabled, weight and Bypass-loading controls. Bypass is a loading method, not the enable switch; model filenames stay private.
- Prompt optimization, low-memory attention, force offload, text-only reference conditioning, sparse attention, separate seeds/steps/denoise/shift settings, face audio constraint and clean-model switches.
- Up to nine reference images, three videos and three audio files, plus an independent face reference. Image mode excludes videos/audio and images after the second. Optional video/audio trims use millisecond timestamps. Face reference is kept separate from the 15-item embedded gallery.
- First/second/refined output retention, ping-pong playback and CRF. At least one active output is required.

All 77 controls are grouped into collapsible sections. Uploads reuse the authenticated same-origin resumable pipeline, capability ownership, magic-byte checks and existing quota protection. Images support clipboard paste and red-dot removal. Video tasks reuse queue editing, cancellation, ownership checks, history, favorites and redo; redo retains original media and settings through the existing server-owned snapshot.

The graph is stored only in the private catalog. Client data cannot override graph wiring, model paths or optimizer credentials/URLs. Embedded sample files are cleared. Output metadata is disabled. The original API workflow ID is used for advanced graph submission; the editor ID is never submitted as a generation endpoint.
