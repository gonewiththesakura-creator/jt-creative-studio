# 图片编辑上传入口修复

图片编辑复用了分块上传客户端，但 `/api/upload-start` 仍只接受 `video` 工作流，因此粘贴和文件选择都会在上传初始化时返回「无效的上传位置」。本地预览已经显示，实际图片还未传输。

上传入口现在接受可信配置中的 `video`、`rh_workflow`、`ai_app`，同时要求后端匹配和素材槽存在。登录、CSRF、套餐上传权限、分块大小、文件格式校验及账号隔离继续生效。

之前的图片编辑浏览器测试模拟了上传端点，未能发现真实 HTTP 入口的类型限制。本次增加真实 HTTP 上传链路回归，覆盖换装两张参考图、普通图片工作流和 AI 应用；账号测试覆盖未登录、错误 CSRF、无效工作流/素材槽、跨账号上传/结束拒绝。78 项测试通过。

生产仅替换 `server.py`。发布事务已提交、清理完成，重启前后 1057 条任务完全一致。

线上使用新建测试会话与纯色测试 PNG 实际验证：通过系统剪贴板写入图片、按 Ctrl+V 上传人物参考图，再通过文件选择上传图二。初始化、分块和完成接口全部返回 200，两张图均显示已上传，生成按钮可用。没有提交生成任务；检查会话已退出。

证据：`audit/image-upload-fix-20261018/release.json`、`live-verification.json`。原页面仍保留图片时，点击「重试上传」即可重新初始化上传，无需重新粘贴。
