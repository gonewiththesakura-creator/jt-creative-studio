## 第二版：按原型改成指令坞布局（同日）

用户确认要的是原型 `accretion/index.html` 的布局本身，不只是配色。第一版保留了"左参数栏 + 右预览"的两栏结构，第二版改为：

- **全屏是黑洞**：外壳内三个页面的预览区铺满窗口；空状态左侧是标题区"向内坠落，向外成像。"；当前作品浮在左侧，
  说明和收藏/下载在右边；缩略图条在指令坞上方居中。
- **创作台底部指令坞**：上面一行是提示词（选项组合时显示自动生成的详细提示词，手动时是正向提示词，旁边有"导入并编辑"和随机），
  下面是"画风 / 人物 / 尺寸 / 数量 / 引擎 / 参数"六个 chip 和火焰"生成 ↑"。点 chip 时指令坞向上展开对应分组，
  原有的全部控件都在里面：10 种画风和冷脸萌分支、原创/角色模式和五个选项抽屉、随机/清空、宽高（新增 5 个比例快捷）、
  批量、负向提示词（手动模式）、高清、种子；引擎里选云端/本地/API，选 API 时旁边出现"设置"打开原 API 浮层。
  选中的引擎按钮就是"生成"；另一个引擎在跑时它的进度按钮会一起显示。
- **图片编辑 / 视频**：原型没有，按同一语言做。表单以上传为主，所以指令坞和面板在宽屏上靠左（约 420px）且默认展开，
  点方案 chip 可收起；作品、缩略图条、示例图在右侧；任务卡保留业务测试约定的 16:10 缩略图"接触印样"（宽 100～250px，
  快捷重做/取消在缩略图内），放在右上角两列，状态用描边颜色和光晕（运行中琥珀，完成绿，失败红）；手机上是顶部一条可滚动的带。
  （曾试过原型里的圆形队列，几十个视频任务时看不到原视频首帧，且违反上述约定，已撤回。）
- 实现：`frontend/accretion-layout.js`（外壳在 `jt:page-mounted` 时重排，只移动少量现有节点并加 chip，业务代码、id、事件不变；
  数值只通过与人操作相同的 input/change 事件写入）和 `frontend/styles/accretion.css`（只打进外壳页面样式）。
  `theme.css` 里旧两栏布局的规则标为 `legacy-only`，外壳页面的副本去掉；页面样式打包时去注释和行首缩进。
- 创作台首屏 gzip 33,532，超过 10-20 定的 32,000；预算改为 34,000（`tests/test_navigation_performance_contract.py` 有说明）。
- 测试按新布局更新了操作路径（`tests/test_app_shell.py`：种子在"参数"里、画风在"画风"里、API 设置需先选 API 引擎；
  手机生成坞测试改为验证固定指令坞 + 面板内滚动）。过程中修了：工作流页观察器写文字导致的死循环、预览层盖住缩略图、
  视频提示卡挡住收藏和翻页（视频页把说明和收藏/下载放到作品上方，翻页箭头放在播放器右上角）、手机上任务卡被表单面板盖住。

## 过程中发现并修掉的

- 手机上收藏/历史抽屉的关闭按钮被外壳顶栏盖住（页面 `.app-shell` 的 `z-index:1` 和页面根的 `isolation:isolate` 各自形成层叠上下文）。
- 第一版给结果图加了"显影"滤镜动画，出图瞬间的像素颜色不准，`test_gallery_image_loading` 抓到后去掉；完成提示只用光子环闪光。
- 第一版皮肤整份复制进每个页面样式，创作台首屏 gzip 超出 32,000 预算（`test_navigation_performance_contract`），见上表 `build_frontend.py`。
- 第一版用 `justify-content:center` 居中缩略图条，320px 宽时溢出部分被推到左侧够不着，第一张缩略图被"上一张"按钮盖住；改为首尾 `margin:auto`。

## 行为变化需要知道的

1. 任务进行时黑洞持续以 30 fps（手机 20 fps）渲染，而不是暂停。以前空闲时本来也是这个帧率，GPU 占用不超过空闲状态；
   用户在"场景 → 暂停光场"或系统"减少动态效果"时，仍只画一帧静止画面（直接显示加速后的亮度）。
2. 收藏/历史抽屉现在盖住整个视口（包括外壳顶栏）。
