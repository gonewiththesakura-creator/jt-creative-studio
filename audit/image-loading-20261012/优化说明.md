# 图片加载优化 · 2026-10-12

已发布至正式工作台，发布状态 `committed`，发布锁与排空开关已恢复。

## 原因与调整

- 原先缩略图和主图均请求原图代理，每张约 5–6 MB；四图同时加载会超过每账号两个媒体流的保护限制，线上日志确认发生 503，原页面没有重试。
- 图片结果现在提供 256px 缩略图和 1536px 展示图，下载按钮仍指向原图。服务器一次下载同时生成两尺寸，同图请求合并；私有派生缓存为 24 小时、512 MiB、2048 文件上限。
- 前端最多同时加载两张，选中图优先；繁忙或临时断网自动重试，仍失败时可点击重试。已看过的图复用当前页面内存，不写入浏览器持久存储；退出、身份过期、换账号时清理。
- 不再在每次账号面板刷新时清空浏览器 HTTP 缓存；首次迁移及身份变化仍清理。匿名和跨账号请求仍被拒绝，媒体响应仍为 `private, no-store`。
- 保持展示区尺寸，加载与切换不再因图片尚未到达而缩放。

## 正式环境实测

使用已有四图任务，只读取结果，没有提交生成、取消任务或更改套餐。

| 项目 | 结果 |
| --- | --- |
| 一张原图 | 5,783,728 字节 |
| 对应缩略图 | 7,671 字节，减少 99.87% |
| 四张缩略图首次生成及响应 | 每张 0.670–0.748 秒 |
| 四张缓存缩略图并发响应 | 每张 0.042–0.051 秒，全部成功 |
| 已缓存主预览 | 146,050 字节，0.022 秒 |
| 原图 Range 下载 | 206，原图完整大小不变 |
| 匿名读取私有预览 | 401 |

以上时延来自服务器访问正式 HTTPS 入口，不代表用户本地网络时延。未命中缓存的旧图需要先获取原始结果一次。
